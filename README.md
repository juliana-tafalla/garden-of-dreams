	<h2>project details</h2>
	<p>
		This repository holds the assets and code for my personal website,“garden of dreams"! It's an introductory and portfolio website I made for fun, which includes a visual novel-like aspect to make it more interesting!
  </p>

  <div>
    The website features:
    <ul>
      <li>An optional introductory cutscene when guests click <code>[start]</code>. Of course, guests can simply navigate through other pages using the navigation bar!</li>
      <li>An experiences page that showcases work experiences/internships I’ve done. Guests can click on <code>[read more]</code> for more details on each work experience.</li>
      <li>An about page that introduces myself. Guests can click on one of the <code>[interests]</code> for more details. Guests can also click on the <code>[image]</code> to shuffle through them!</li>
      <li>A randomly assigned illusory guide, which changes every time the website is opened (ie. a new session)! Guests can click the <code>[wings]</code> button on the right for simple interactions. Perhaps other secret interactions are waiting to be found!</li>
    </ul>
    <p>
      It’s not a typical or traditional portfolio website, I know, but I still had a lot of fun putting it all together! I wanted to create something fancy for myself, which gave me an opportunity to showcase my talents through this project. I expect “garden of dreams” to be an ongoing project that will be updated occasionally and as needed. For now, the website is hosted with GitHub Pages.
    </p>
    <strong>miscellaneous notes:</strong>
    <ul>
      <li>There are only two illusory guides right now, but I really loved the idea of them guiding guests, so I'd love to add more in the future!</li>
      <li>Most images used in the project (ie. artwork, in-game screenshots, etc.) are mine, but some images don’t belong to me. The text file <code>misc-sources.txt</code> contains links to the sources of such images.</li>
      <li>This README file was written with the help of this template: <a href="https://github.com/othneildrew/Best-README-Template">https://github.com/othneildrew/Best-README-Template</a> and this repository for the badges: <a href="https://github.com/alexandresanlim/Badges4-README.md-Profile">https://github.com/alexandresanlim/Badges4-README.md-Profile</a>. I liked the way the template was formatted and I thought it was cool to have these badges, which I incorporated here! 
      </li>
    </ul>

    The project is relatively simple since I mainly wanted to refresh my art and coding skills.
    <br /><br />
    All digital artworks for the website are, in fact, drawn by me in ibisPaint X (so, uh, please don’t mind any imperfections, haha…). Just to be on the safe side (since this is the first time I’m putting my artwork out on the internet), please don’t steal my artwork for any purpose without my explicit permission. Thank you! 
    <br /><br />
    I wanted to refresh my memory on both vanilla CSS and Tailwind CSS, which is why I decided to use them together. I liked the convenience of styling elements directly in the HTML, but I also didn’t want the HTML to be cluttered with Tailwind classes, especially if they were commonly used across pages. I figured I’d use CSS for general and complex styling across pages, while I’d use Tailwind CSS for unique styling.
    <br /><br />
    Similarly, I also wanted to refresh my memory on both JavaScript and jQuery. I actually learned and used jQuery a little bit during my work term, and I liked how it simplifies JS coding, which is why I decided to use this JS library.
